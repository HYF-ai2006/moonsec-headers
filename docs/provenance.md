# 来源、AI 辅助与许可证说明

## 实现来源

moonsec-headers 是面向 MoonBit 的原创实现，不是其他项目的直接移植，也不复制其他审计工具的源码。核心实现、公开 API、规则 ID、profile、策略模板和报告格式均由本项目维护。

项目仅使用 MoonBit 官方 core 包。测试 fixture 是仓库内自制的短文本，不包含真实站点响应、凭据、图片、音频、字体或来源不明素材。

## AI 辅助边界

开发过程中可以使用 AI 辅助方案讨论、代码草拟、测试补全、错误解释和文档整理；参赛者对最终代码的正确性、安全性、可维护性、功能边界和许可证合规负责。公开提交前，代码必须经过本地检查、构建、测试和人工复核。

## 生成文件

`pkg.generated.mbti` 和 `cmd/main/pkg.generated.mbti` 是 MoonBit 工具链根据公开 API 生成的接口文件，不包含外部源码。修改公开 API 后应运行 `moon info` 并检查生成接口差异，不应手工伪造接口内容。
